# Python for Security

A collection of small Python projects and experiments related to cybersecurity, network tooling, and automation.

Each tool should have its own description, dependencies, example invocation, expected output, error handling, limitations, and safe-use notes.

## Related repositories
- [Hillary — scheduled MAC address change experiment](https://github.com/Afukam/Hillary)
- [Christiania — network scanning project](https://github.com/Afukam/Christiania)
- [Pius — Python Nmap utility](https://github.com/Afukam/Pius)

## Project documentation standard
For every script, document the problem it explores, Python version and dependencies, installation and usage, expected input/output, known limitations, and safety boundaries.

Use network tools only on systems and networks you own or are explicitly authorized to test. Never commit API keys, passwords, tokens, private keys, or unredacted third-party scan results.
